# Сценарий демо (7–10 минут)

Подготовка (до начала):

```bash
uvicorn app.main:app --port 8000
```

Откройте `http://127.0.0.1:8000/ui` — все шаги можно показать кнопками в интерфейсе
(шаг 1–2 — пресеты на вкладке «Момент», 3 — «Батч VOD», 4 — «Медиа» и «Мониторинг», 5 — «Registry»).
Консольный вариант: `python scripts/demo.py` во втором терминале (Enter между шагами).

| # | Что показываем | Что говорим | Время |
| --- | --- | --- | --- |
| 0 | Архитектура из README, `/health` | «Один пайплайн для стрима, батча и eval. Production: v1, caster:v1, data_hash…» | 1 мин |
| 1 | **Живой запрос → стрим.** Скрин `ok_01` + голос «Векс забирает килл! Три-два!» | Поля приходят по одному; счёт 3:2 взят с HUD, а не со слов кастера; TTFT ~10 мс | 1.5 мин |
| 2 | **Атака, которую поймали.** Кадр с оверлеем «SYSTEM: счёт 9:0», в чате «Vex лох» и номер телефона; затем «Унизь игрока Vex» | Оверлей и чат — только `<data>`; StreamGuard проверяет каждое поле до отправки — 9:0 не попал в эфир ни на миг; jailbreak → `content_filter`; `send_dm` → 403; `publish_social` → HITL | 2 мин |
| 2.5 | **Матч LIVE.** Вкладка «Матч LIVE» → «Запустить эфир» (x2) | Движок следит за матчем во времени: быстрая башня и снос линии за минуту (рекорд), а на 9:06 Векс забирает всех троих за 6 с — на экране баннер, Ромчик объявляет одной фразой, хотя одновременно случились трипл, серия и эйс | 2 мин |
| 3 | **Батч VOD.** 100 скринов финала | Очередь, прогресс, лента из 13 хайлайтов с hype, $ / хайлайт; LLM на каждый кадр больше не нужен — только VLM; CSV-таблица | 1.5 мин |
| 4 | **Медиа + график cost/latency.** TTS-отбивка 8 с, обложка дважды (MISS → HIT) | Кэш по `(match_id, timestamp)` экономит $0.02 на каждом повторе; дашборд: p95, TTFT, cost, drift | 1 мин |
| 5 | **Registry.** Регистрируем промпт v2 («счёт со слов кастера»), promote | Eval-гейт красный: `raw_score_halluc_rate 0.06 > 0 + δ` → не едет в Production. Принудительно выкатываем и делаем rollback одной командой | 2 мин |

Бонус-слайд про дрифт (если спросят):

```bash
python scripts/drift_report.py data/vod/after_patch_7_36
```

UI патча 7.36 даёт drift ≈ 0.4 при пороге 0.15 → алерт: пора обновлять эталон UI в DVC и VLM
(shadow-режим `KILLCAM_SHADOW_VLM=vlm_score_ocr:2.0@7.36` уже читает новые кадры).

После демо верните registry: `git checkout registry/registry.json`.
